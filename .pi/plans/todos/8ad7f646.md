# Objective

Refactor parser internals to enforce strict invariants and produce typed parse diagnostics for all malformed unified diff inputs.

# Scope

In scope:
- lexical token validation for file and hunk headers
- structural hunk count validation
- deterministic operation derivation for create, edit, move, delete
- typed parse error payload wiring

Out of scope:
- fuzzy healing behavior
- commit transaction changes

# Observable outcomes

- malformed patch inputs fail with deterministic `PatchParseError` payloads
- valid create, edit, move, delete patches parse into stable AST nodes
- parser outputs include line offsets needed by downstream diagnostics
